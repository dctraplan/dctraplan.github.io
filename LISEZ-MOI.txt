RÉEL JUST JACK — SITE WEB GRATUIT

1. Ouvrir index.html avec un navigateur pour voir le site sur votre ordinateur.
2. Pour le mettre en ligne gratuitement :
   - Créer un compte GitHub si nécessaire : https://github.com
   - Créer un dépôt public nommé reel-just-jack
   - Importer les fichiers index.html, style.css, script.js et le dossier assets à la racine du dépôt (ne pas importer seulement le ZIP).
   - Dans Settings > Pages, sélectionner Deploy from a branch, branche main et dossier /(root), puis enregistrer.
   - Le site sera accessible à https://VOTRE-PSEUDO.github.io/reel-just-jack/ après publication.

IMPORTANT : GitHub Pages est un hébergement public. Ne pas y mettre de données privées.
Le lecteur Twitch apparaît automatiquement sur le site public en HTTPS. En aperçu local, un encart remplace le lecteur.
Le lien YouTube pointe vers https://www.youtube.com/@MisterJackBond. Discord n'est pas encore renseigné.
Le planning affiché est indicatif et peut être modifié dans index.html.
Ce site est indépendant de WordPress et ne modifie pas votre site WordPress existant.
