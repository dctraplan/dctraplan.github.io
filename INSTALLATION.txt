INSTALLATION GITHUB PAGES
1. Décompressez l'archive.
2. Ouvrez votre dépôt GitHub Pages dctraplan.github.io.
3. Ajoutez TOUS les fichiers et le dossier assets à la racine du dépôt (pas dans un sous-dossier).
4. Validez les changements avec Commit changes.
5. Attendez le déploiement GitHub Pages puis rechargez le site avec Ctrl+F5.

TEST LOCAL
Ouvrez index.html dans votre navigateur. Certaines intégrations externes (Twitch) peuvent nécessiter un hébergement HTTPS et un domaine autorisé.

ATTENTION
- Le lecteur Twitch dépend des règles d'intégration Twitch et du nom de domaine utilisé.
- Le planning est indicatif, à adapter avant publication.
- La galerie de clips pointe vers les chaînes : elle n'est pas une synchronisation automatique des derniers clips.
- Le site n'utilise pas de base de données. Les favoris et la progression sont enregistrés localement dans le navigateur.
- Vérifiez les liens des talents et les contenus WoW avant mise en ligne.
